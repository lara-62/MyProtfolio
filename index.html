Research

  1. Automated Blackbox Fuzzing of Restful APIs

    Undergraduate thesis work
    Co-authors: Mr. Arnob Saha Ankon Dr. Md. Shohrab Hossain (Supervisor)
    Keywords: Fuzzing , API Security

    This thesis focuses on automated black-box fuzzing of RESTful APIs to identify security vulnerabilities and unexpected application behavior without requiring access to source code. The research explores API specification-guided test generation, stateful request sequencing, and dynamic extraction and reuse of response values to handle dependencies between API operations. The goal is to improve the effectiveness of automated API testing by generating meaningful request sequences and uncovering vulnerabilities in real-world web applications.
